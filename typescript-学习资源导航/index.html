# TypeScript 学习资源导航

本文作者:阳九五 (opens new window)

本站地址:https://blog.56321654.xyz (opens new window)

TypeScript 是 JavaScript 的超集,为 JS 加上可选的静态类型系统。无论是想入门还是查漏补缺,下面两个中文教程站都很值得收藏——一个适合按序学习,一个适合随时查阅。

# 🥇 TypeScript 入门教程(小角标 / 刘欣)

  • 站点:https://ts.xcatliu.com/ (opens new window)
  • 作者:xcatliu,开源教程,附 GitHub 仓库
  • 许可:CC BY-NC 4.0(署名-非商用)

一句话定位:从 JavaScript 程序员的角度组织,循序渐进理解 TypeScript。

这个站点不像官方手册那样按功能分章,而是按学习路径组织,示例丰富、表述简洁,对初学者更友好。内容分五个部分:

部分 内容
简介 什么是 TypeScript、安装、Hello TypeScript
基础 原始数据类型、任意值、类型推论、联合类型、接口、数组、函数、类型断言、声明文件、内置对象
进阶 类型别名、字符串字面量类型、元组、枚举、类、类与接口、泛型、声明合并、装饰器、扩展阅读
工程 代码检查(lint)、编译选项
感谢 —

适合:熟悉 JavaScript 和 ES6、会用 npm,想入门 TypeScript 的人;不适合没系统学过 JS 的人,也不适合已经熟练使用 TS 的开发者。

# 🥈 TypeScript 教程(网道 / WangDoc)

  • 站点:https://wangdoc.com/typescript/ (opens new window)
  • 作者:网道(WangDoc),阮一峰旗下开源文档计划
  • 许可:CC BY-SA 3.0

一句话定位:面向初学者的 TypeScript 开源教程,覆盖面广、体系完整。

它不止讲入门基础,还深入类型系统的高级用法与工程实践,共 26 章,按主题组织:

分类 章节
入门基础 简介、基本用法、any 类型、类型系统、数组、元组、symbol
核心语法 函数、对象、interface、类、泛型、Enum、类型断言
工程组织 模块、namespace、装饰器(新/旧语法)
类型进阶 declare 关键字、d.ts 声明文件、类型运算符、类型映射、类型工具、注释指令
工具配置 tsconfig.json、tsc 命令

适合:想系统学习、尤其是需要查泛型/类型工具/d.ts 等进阶主题的读者。

# 💡 怎么选

  • 入门按序读 → 小角标(TypeScript 入门教程),路径清晰、循序渐进;
  • 进阶/查阅 → 网道,章节细、覆盖全,适合当工具书随时翻;
  • 两者都是免费中文教程,配合 TypeScript 官方手册 (opens new window)一起用效果更佳。
